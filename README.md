# Train App

A mobile-friendly web app hosted on **GitHub Pages**.

## 🌐 Live URL

Once deployed, your app will be available at:

```
https://<your-github-username>.github.io/train/
```

Replace `<your-github-username>` with your actual GitHub username.

## 🚀 How to host your app here

1. **Replace `index.html`** with your app's HTML/CSS/JS.
2. **Push to the `main` branch** — the GitHub Actions workflow (`.github/workflows/deploy.yml`) will automatically deploy to GitHub Pages.
3. **Enable GitHub Pages** in your repo settings (if not already enabled):
   - Go to **Settings → Pages**
   - Under *Source*, select **GitHub Actions**
4. Visit your live URL above from your phone or any browser.

## 📁 Files

| File | Purpose |
|------|---------|
| `index.html` | Your app's entry point — edit this with your own content |
| `.github/workflows/deploy.yml` | Auto-deploys to GitHub Pages on every push to `main` |
